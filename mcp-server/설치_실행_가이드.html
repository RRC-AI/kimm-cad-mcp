KIMM-CAD V26 MCP 설치 및 실행

PowerShell에서 설치한 뒤 Codex와 KIMM-CAD V26을 다시 시작하면 됩니다.

1. 프로젝트 폴더로 이동

cd "<배포 폴더>\kimm-cad-mcp_share"

2. 설치

ZIP을 완전히 푼 뒤 INSTALL.cmd를 더블클릭합니다. 명령줄에서는 다음과 같습니다.

.\INSTALL.cmd

SETUP COMPLETE가 표시되면 설치가 끝난 것입니다.

3. 다시 시작

Codex와 KIMM-CAD V26을 모두 종료했다가 다시 실행합니다.

4. Codex에서 실행

KIMM-CAD V26을 켜 둔 상태에서 Codex에 다음처럼 요청합니다.

가로 40mm, 세로 30mm, 높이 20mm 직육면체를 KIMM-CAD에 만들어줘.

V26 화면에 모델이 나타나고 cad_status()의 kimm_cad_version이 V26.1이면 정상입니다.

V26이 기본 경로가 아닌 곳에 설치되어 있다면 KIMM_CAD_EXE에 KIMM-CAD V26.exe 전체 경로를 지정한 뒤 다시 설치하세요. 별도 프로필에는 KIMM_CAD_PROFILE_ROOT를 사용합니다.
