# 예시 프롬프트

## MCP: 기본 형상 생성

```text
KIMM-CAD V26 MCP를 사용해서 볼트 구멍 4개가 있는 원형 플랜지를 만들어줘. 모든 치수는 mm야.
(상세 치수) 외경 80, 중앙 관통 구멍 지름 20, 두께 8, 볼트 관통 구멍 지름 6, 총 4개
(세부 조건) 볼트 구멍 중심은 플랜지 중심 기준 지름 60인 원 위에 90도 간격으로 배치
플랜지 중심축은 Z축이고, 바닥면은 Z=0, 하나의 연결된 솔리드로 만들어줘.
```

## 도면 → 3D: 단일 부품

```text
input 폴더의 part.dxf를 두께 12mm로 압출해서 STEP과 STL로 변환해줘.
```

## 도면 → 3D: DWG 조립도 전체 모델링

```text
아래 DWG 도면을 해석해서 각 부품을 새로 3D 모델링하고, 도면에 표시된 조립체로 조립해줘.
원본: <DWG 파일의 절대 경로>
기존 STEP·STP·FCStd의 형상을 참조하거나 복사하지 말고, 이 DWG의 형상과 치수를 근거로 작업해줘.
1. DWG를 DXF로 변환하고 실제 벡터 형상, 치수, 부품번호, BOM을 분석해줘.
2. 부품별 정면도·평면도·측면도·단면도를 대응시켜 외형, 두께, 구멍, 홈, 축 형상을 확인해줘. 여러 투상도를 한꺼번에 돌출하지 마.
3. 각 부품을 돌출·회전·절삭 등으로 새로 모델링하고, 주요 치수를 도면과 대조해줘.
4. 현재 열린 KIMM-CAD V26 창에서 부품이 만들어지는 과정을 순서대로 보여줘. 지원되는 MCP 도구를 사용하고, 외부에서 형상을 생성했다면 방금 DWG에서 새로 만든 부품을 표시해줘.
5. 도면의 조립도와 BOM을 기준으로 부품 수량, 방향, 결합면과 위치를 결정해서 하나의 조립체로 구성해줘. 부품별 이름과 계층 구조를 유지해줘.
6. 각 부품의 형상 유효성·치수와 최종 조립체의 수량·배치·간섭을 검증해줘.
7. 부품별 STEP과 최종 조립체 STEP·FCStd를 저장하고, KIMM-CAD에 완성된 조립체를 등각 보기로 열어 둬.
DWG에서 확인할 수 없는 치수나 조립 위치는 임의로 만들지 말고, 부족한 항목을 정리해서 질문해줘. 확인 가능한 부품은 계속 진행해줘.
완료 보고에는 DWG에서 새로 모델링한 부품 목록, 검증 결과, 미확정 항목과 저장 경로를 포함해줘.
```
