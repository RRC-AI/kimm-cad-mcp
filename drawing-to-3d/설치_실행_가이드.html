도면 3D 변환기 설치·실행 가이드

1압축 풀기

ZIP을 원하는 위치에 풀고 도면3D변환기_share 폴더를 엽니다.

2INSTALL.cmd 실행

INSTALL.cmd를 더블클릭합니다. 필요한 설치 작업은 자동으로 실행됩니다.

정상 완료 메시지 
[Completed] drawing-file-to-3d skill is installed.
Restart Codex once so the skill list is refreshed.

3Codex 재시작

Codex를 완전히 종료했다가 다시 실행합니다. 재시작 후 drawing-file-to-3d skill이 인식됩니다.

4변환 실행

변환할 DXF, DWG, IFC, PDF 파일을 input 폴더에 넣고 Codex에 다음과 같이 요청합니다.

input 폴더의 part.dxf를 두께 12mm로 압출해서
STEP과 STL로 변환해줘.

결과는 기본적으로 이 프로젝트의 output 폴더에 생성됩니다.

  • output\part.step
  • output\part.stl

결과 STEP 파일은 KIMM-CAD V26에서 열 수 있습니다. Codex에서 화면 표시와 검증을 사용하려면 kimm-cad-mcp_share를 먼저 설치하세요.

한 장의 2D 도면에 두께가 표시되지 않았다면, 압출 두께를 같이 알려주세요.
